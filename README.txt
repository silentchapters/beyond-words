BEYOND WORDS — update package

Files:
- index.html
- style.css
- script.js

How to use:
1. Open your GitHub repository: silentchapters/beyond-words
2. Replace the existing index.html, style.css and script.js with these files.
3. Commit the changes.
4. Wait for GitHub Pages to publish, then test on desktop and phone.

Behaviour included:
- Six moving stars: Memories, Promises, Gratitude, Dreams, Prayer and Devotion.
- After three different stars have been opened, Beyond Words appears and stays visible.
- Beyond Words opens a separate envelope.
- The wax seal reads “Confidential for My Actress”.
- Pressing the seal animates the envelope and unfolds the Beyond Words letter.

Note:
This package is a first implementation pass. The letters are included as the latest drafts available in this conversation. Please review the Khasi lines and the long letters on mobile after publishing.
